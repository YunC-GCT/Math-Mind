# MathMind 主 agent 回复风格测试集

> 日期：2026-07-19
> 目标：验收主 agent 普通对话是否摆脱“一句话式回复”，并保持数学助手应有的清晰、分层、可执行。

## 一、参考回答形态

主流 AI 助手的稳定回答形态可以概括为：

- 先判断用户意图，再决定回答深度。
- 简单问题直接答，复杂问题分层展开。
- 数学、代码、推理类任务给关键步骤和最终结论。
- 总结、复盘、整理类任务使用标题、要点、待办或结论块。
- 信息不足时先说明假设，必要时追问，不编造。
- 不用固定模板压所有问题，也不为了显得简洁牺牲关键信息。

参考资料：

- OpenAI Model Spec: https://model-spec.openai.com/2025-09-12.html
- Anthropic Prompt Engineering Overview: https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview
- Google Gemini Prompt Design Strategies: https://ai.google.dev/gemini-api/docs/prompting-strategies

## 二、通过标准

| 项 | 通过标准 |
|----|----------|
| 普通短问答 | 可以简短，但不能机械套话 |
| 数学解题 | 至少包含思路、关键步骤、答案 |
| 概念解释 | 根据画像调整解释密度，不强制每次都输出完整四段式 |
| 总结整理 | 不只输出一句话，至少有 2-4 个要点 |
| 信息不足 | 明确缺什么，先给合理假设或追问 |
| 笔记意图 | 只有明确保存/生成笔记时才进入笔记链路 |
| 非笔记总结 | “总结一下/整理一下”默认只回答，不自动生成笔记 |
| 画像自适应 | 同一问题在 beginner/novice/advanced 下有明显粒度差异 |
| 默认画像 | 无历史画像时默认 advanced，回答更偏公式、结论和关键边界 |

## 三、测试用例

### RS-01 简单计算

输入：

```text
解方程 2x + 3 = 11
```

期望：

- 不只说 `x=4`。
- 应包含移项、除以 2、最终答案。
- 3-6 行即可，不需要长篇。

### RS-02 复杂一点的数学题

输入：

```text
求函数 f(x)=x^3-3x^2+2 的极值点
```

期望：

- 写出 `f'(x)`。
- 解临界点。
- 用二阶导或单调性判断极大/极小。
- 给出极值点坐标。

### RS-03 概念讲解

输入：

```text
为什么导数可以表示瞬时变化率？
```

期望：

- 先给直观解释。
- 再说明割线斜率到切线斜率的极限。
- 可以给一个简单例子。
- 不应只有一句定义。

### RS-04 临时总结，不生成笔记

输入：

```text
把刚才讲的二次函数判别式整理一下
```

期望：

- 输出结构化总结。
- 不应生成笔记，不应出现“已生成笔记”。
- 至少包含定义、三种判别情况、用途。

### RS-05 明确生成笔记

输入：

```text
把上面这个二次函数判别式知识点记到笔记里
```

期望：

- 进入生成笔记流程。
- 成功时回复 `已生成笔记：...`。
- 不应只做普通聊天总结。

### RS-06 信息不足

输入：

```text
这题怎么做？
```

期望：

- 不编造题目。
- 提醒用户补充题目或图片。
- 可以说明“如果是刚才那题，我可以继续按上文讲”。

### RS-07 复盘类请求

输入：

```text
我刚才哪里容易错，帮我复盘一下
```

期望：

- 使用分点结构。
- 包含错误位置、原因、改法、下次检查点。
- 不应只有一句“注意公式和计算”。

### RS-08 学习计划

输入：

```text
我三天后要考导数，帮我安排一下复习
```

期望：

- 按天拆分。
- 每天包含复习内容和练习重点。
- 可以给验收方式。

### RS-09 长上下文追问

输入：

```text
沿着上面那道题继续讲，为什么这里要分类讨论？
```

期望：

- 使用会话记忆中的相关内容。
- 先指出分类讨论的触发条件。
- 再解释每类差异。
- 如果上下文缺失，应说明需要补题。

### RS-10 口语化保存意图

输入：

```text
这个挺重要，帮我记一下
```

期望：

- 判定为生成笔记意图。
- 生成笔记，而不是只回复“好的我记住了”。

## 四、画像差异测试

### LP-01 同一概念题按画像调整

输入：

```text
为什么导数可以表示瞬时变化率？
```

画像预置与期望：

| 画像 | 期望 |
|------|------|
| `beginner` | 有直观比喻或小例子，解释平均变化率如何逼近瞬时变化率，可以提示“不要把导数只理解成公式”。 |
| `novice` | 有极限定义和简短解释，说明割线斜率到切线斜率即可，不必展开完整常见误区。 |
| `advanced` | 直接给 `f'(a)=lim_{h→0}(f(a+h)-f(a))/h`、几何含义和适用条件，压缩基础比喻。 |

### LP-02 当前指令覆盖画像

输入：

```text
像小白一样讲一下链式法则
```

画像预置：`advanced`

期望：

- 本轮按小白讲。
- 有直观解释和例子。
- 不应因为画像是 `advanced` 而只给公式。

### LP-03 简短指令覆盖画像

输入：

```text
直接给答案，不要展开：sin x 的导数是什么？
```

画像预置：`beginner`

期望：

- 简短回答 `cos x`。
- 最多补一句“即 (sin x)' = cos x”。
- 不展开直观理解和常见误区。

### LP-04 画像更新节奏

输入序列：

```text
我完全没学过导数
能不能从最基础开始
这个符号是什么意思
为什么 h 要趋近 0
我还是没懂切线
能不能举生活例子
```

期望：

- 第 6 条用户消息后可以更新画像。
- 会话画像倾向 `beginner`。
- evidence 简短，例如“多次要求基础解释和例子”。

### LP-05 笔记意图不受画像影响

输入：

```text
这个挺重要，帮我记一下
```

画像预置：任意

期望：

- 仍判定为生成笔记意图。
- 生成笔记，而不是只做普通聊天或画像更新。
