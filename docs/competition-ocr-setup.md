# Math_Mind 比赛 OCR 启动说明

## 交付方式

当前 OCR 不打进手机 HAP。项目目录内包含一个伴随 OCR 服务：

- 服务目录：`tools/ocr_service`
- 一键启动：`start_ocr_server.bat`
- App 调用：HTTP `POST /api/v1/ocr/recognize`

这样提交 `Math_Mind` 项目文件时，OCR 服务源码和启动脚本会一起交付；演示时在电脑上启动服务，手机/模拟器上的 App 调用这台电脑的局域网地址。

## 启动步骤

1. 在运行 OCR 的电脑上进入项目根目录。
2. 双击或命令行执行：

   ```bat
   start_ocr_server.bat
   ```

3. 等脚本输出 `Enter this in the app OCR setting`，记录下面那一行 IPv4，例如：

   ```text
   192.168.1.50
   ```

4. 在 App 的 AI 设置页里打开 OCR，服务地址只填这个 IP 即可。
5. OCR 模式默认选“快速”，点击“测试连接”，通过后再拍照或选图识别。

## IP 应该填什么

填写运行 OCR 服务那台电脑的局域网 IPv4，不是虚拟机 IP。

- 正确：OCR 服务电脑脚本打印的 `192.168.x.x`
- 也可以：`192.168.x.x:8000`
- 也可以：`http://192.168.x.x:8000/api/v1/ocr/recognize`
- 不要填：`127.0.0.1`，除非 App 和 OCR 服务运行在同一个系统环境里

App 会自动把纯 IP 补全成：

```text
http://<OCR服务电脑IP>:8000/api/v1/ocr/recognize
```

## 手动检查

在虚拟机或 App 所在机器里测试网络连通：

```bat
curl http://<OCR服务电脑IP>:8000/api/v1/formula/health
```

返回 `status: ok` 表示服务可达。

## 性能和精度策略

- 快速模式：只跑文字 OCR，不跑 CPU 公式模型，适合整页资料、截图、题干识别。
- 公式模式：文字 OCR + 公式 OCR，适合裁剪后的单块公式或单道题，不适合整页公式汇总。
- 自动模式：服务端根据图片形态和文字行数判断是否跑公式 OCR；整页/长图会跳过公式 OCR。
- App 端当前不压缩 OCR 图片，拍照/相册解析出来的图片会原样上传给 OCR 服务，优先保障识别细节。
- 客户端不做灰度化、二值化、锐化，避免和服务器端预处理重复叠加。
- 服务器端仍负责文字 OCR 预处理和公式图缩放，识别精度以服务器端模型输出为准。
- 服务端公式 OCR 默认 30 秒超时，超时后返回已有文字 OCR 结果，不让 App 卡死。
- 公式结果如果出现超长、重复字符、中文乱码比例过高，会被服务端过滤，不再拼进笔记生成输入。
- 公式/自动模式会先粗裁白色文档区域，再用投影法找少量疑似公式块；第一版不是完整版面分析，不保证整页所有公式逐条识别。
- 每张图最多送 3 个公式候选块进公式模型，避免整页图拖垮演示。
- 如果识别很慢，优先看服务端日志里的 `formula_ocr_ms`；如果该字段很大，慢的是公式模型 CPU 推理，不是上传。

## 图片输入建议

- 不要把手机相册预览页整张截图发给 OCR；顶部状态栏、日期、底部工具栏都会干扰识别。
- 识别公式时先裁剪到白色文档区域，最好只保留一道题或一块公式。
- 整页公式汇总优先使用快速模式，让 AI 根据文字 OCR 结果整理；需要 LaTeX 时再单独裁公式区域使用公式模式。
