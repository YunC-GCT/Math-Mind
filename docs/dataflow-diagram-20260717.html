二、各阶段数据格式

阶段 1 · UiService.capture → Dispatcher

DispatchRequest {
  source: 'app',
  payload: ImagePayload {
    kind: 'image',
    imageUri: "/data/storage/el2/base/.../capture_xxx.png",
    userText?: "整理成笔记"
  }
}

ImageUriResolver 已将 file://media 复制到沙箱 cacheDir/mathmind_capture/

阶段 2a · OcrTool HTTP POST → OCR 服务返回

OcrResponse {
  success: boolean, // true
  formula_count: number, // 5
  formulas: string[], // ["\\frac{x}{y}", "E=mc^2", ...]
  text_line_count: number, // 10
  text_lines: string[], // ["已知函数 f(x)", ...]
  text: string, // "已知函数 f(x) 求下列极限 解："
  message: // "识别到 5 个公式、10 行文字"
}

toPromptText: text + "\n\nLaTeX formulas:\n" + formulas.join('\n')

阶段 2b · TypeClassifier.classify → Dispatcher

ClassificationResult {
  type: '概念' | '计算' | '证明',
  subject: '高等代数' | '数学分析' | '解析几何',
  chapter?: "微分中值定理",
  confidence: number, // 0.85
  ocrText?: // OCR 返回的完整文本
}

LLM 分类失败时降级 ruleFallback (关键词匹配: 证明/求证→证明, 求/计算→计算, 默认→概念)

阶段 3a · KnowledgeModel LLM 调用返回

AiRawResponse {
  category: KnowledgeCategory, // '概念'|'定理'|'公式'|'证明题'|'计算题'
  title: string, // "拉格朗日中值定理"
  tags: string[], // ["概念", "中值定理", "微分"]
  difficulty: number, // 3 (1~5)
  importance: number, // 4 (1~5)
  fields: StructuredField[] [
    { key: "definition", label: "定义", value: "..." },
    { key: "properties", label: "性质", value: "..." },
  ]
}

buildPrompt: ~270 行中文 system prompt 指导 AI 按 Schema 填充结构化字段

阶段 5 · NoteItemMapper → UI 视图模型

NoteItem {
  id:     number,  // stableNumericId(rawId): hash 字符串→32位整数
  title:   string,
  type:    string,  // tags[1] 或 "笔记" (分类标签)
  subject: string,  // tags[0] 或 "数学" (学科标签)
  chapter: string,  // source 或 subject
  conf:    number,  // confidence(KnowledgeUnit): 0.45~0.95
  body:    string,  // content 或 summary
  tags:    string[], // KnowledgeUnit.tags 原样
  date:    string,  // dateText(createdAt): "2026-07-17"
  rawId:   string,  // KnowledgeUnit.id 原样 (删除/更新用)
}

ReviewStatus→confidence 映射: GRADUATED=0.95, REVIEW=0.86, LEARNING=0.72, LAPSED=0.45, 默认=0.64

刷新机制

AgentFloatWindow 保存/删除笔记 → AppStorage.setOrCreate('notesVersion', cur+1)
HomePage/NotesPage: @StorageProp('notesVersion') @Watch('onNotesVersionChange') → loadNotes()
删除流程: confirmDelete → parent.deleteNote → await deleteById → await loadNotes → bumpVersion

四、降级/异常路径

OCR 返回空 (image/file 无文字)

Dispatcher.buildFallbackUnit(type, subject, chapter) → KnowledgeUnit {
  title: "概念 · 高等代数 (待补充)",
  content: "[OCR 未识别到内容，请人工补充题目详情]",
  summary: "OCR 暂不可达，已保存框架笔记，请手动编辑补充",
  difficulty: MEDIUM, source: "camera_capture"
}

不调 LLM，直接构造最小 KnowledgeUnit 存入 RDB

KnowledgeModel LLM 返回空

KnowledgeModel.buildFallbackFromClassify(ocrText, type, subject, chapter) → KnowledgeUnit {
  title: OCR 首行 或 "笔记 · 高等代数",
  content: ocrText 原文,
  tags: [type, subject, chapter],
  difficulty: MEDIUM
}

用 TypeClassifier 已有分类结果构造基础笔记，不丢 OCR 数据

TypeClassifier LLM 不可用

ruleFallback(ocrText, confidence) → ClassificationResult {
  type: ruleType(text),  // 关键词: 证明/求证→证明, 求/计算→计算, 默认→概念
  subject: ruleSubject(text),  // 关键词: 矩阵/行列式→高代, 积分/极限→数分, 曲线/向量→几何
  confidence: 0.4 ~ 0.5
}
