零 · Agent 调度架构

⚠️ 关键约束：子 Agent 之间不直接通信，所有调度必须经过主 Agent (Dispatcher)

TypeClassifier 和 KnowledgeModel 互不知道对方存在。Dispatcher 是唯一的调度中枢：
Step 1: TypeClassifier.classify() → 拿到分类结果
Step 2: KnowledgeModel.structure() → 拿分类结果作为 hint 注入 → 结构化输出
禁止：TypeClassifier 直接调 KnowledgeModel；KnowledgeModel 直接调 TypeClassifier 

flowchart LR
    AI["AiService\n(入口)"]
    DP["Dispatcher\n(主 Agent · 调度中枢)"]
    TC["TypeClassifier\n(子 Agent 1 · 分类)"]
    KM["KnowledgeModel\n(子 Agent 2 · 结构化)"]
    OC["OcrTool\n(OCR 工具)"]
    LLM["DeepSeek LLM"]

    AI -->|dispatch(req)| DP
    DP -->|Step 1: classify()| TC
    DP -->|Step 2: structure()| KM

    KM -->|结构化调用| LLM
    DP -->|返回 KnowledgeUnit| AI

    TC -.-x|"❌ 禁止直接调用"| KM
    KM -.-x|"❌ 禁止直接调用"| TC

三、各阶段数据格式

阶段 1 · DispatchRequest (AiService → Dispatcher)

DispatchRequest {
  source: 'app',
  payload: ImagePayload {
    kind: 'image',
    imageUri: "/data/storage/el2/base/.../capture_xxx.png",
    userText?: "整理成笔记"
  }
}

阶段 2a · OcrResponse (OcrTool → TypeClassifier)

OcrResponse {
  success: boolean,
  formula_count: number,  // 5
  formulas: string[],  // ["\\frac{x}{y}", "E=mc^2", ...]
  text_line_count: number,  // 10
  text_lines: string[],
  text: string,  // "已知函数 f(x) 求下列极限 解："
}

toPromptText: text + "\n\nLaTeX formulas:\n" + formulas.join('\n')

阶段 2b · ClassificationResult (TypeClassifier → Dispatcher)

ClassificationResult {
  type: NoteCategory,  // '概念' | '定理' | '公式' | '证明题' | '计算题'
  subject: string,  // LLM 自由判定 (高等代数/数学分析/解析几何/概率论/数论/…)
  chapter?: string,  // "微分中值定理"
  confidence: number,  // 0.85
  ocrText?: string  // OCR 返回的完整文本
}

type 五分类与 KnowledgeModel KnowledgeCategory 完全对齐 · LLM 失败降级 ruleFallback (关键词匹配)
subject LLM 自由判定 · ruleFallback 用关键词推断默认三门

阶段 3a · AiRawResponse (KnowledgeModel LLM 返回)

AiRawResponse {
  category: KnowledgeCategory,  // 五分类
  title: string,  // "拉格朗日中值定理"
  tags: string[],  // ["概念","中值定理","微分"]
  difficulty: number,  // 3 (1~5)
  importance: number,  // 4 (1~5)
  fields: StructuredField[] [
    { key: "definition", label: "定义", value: "…" },
    { key: "properties", label: "性质", value: "…" },
  ]
}

阶段 3b · KnowledgeUnit (→ NoteDao → RDB)

KnowledgeUnit {
  id: "KB-mrova192-b205om",
  title: "拉格朗日中值定理",
  content: // OCR 原文
  summary: // fields 拼接 ≤100字
  tags: string[],
  difficulty: DifficultyLevel,  source: string,
  createdAt: number,  updatedAt: number,
  reviewStatus: ReviewStatus,
  nextReviewAt/intervalDays/easeFactor/repetitions: number,
  prerequisites: string[],  related: string[],  embedding: number[],
  userId: string,  version: number
}

RDB Schema · knowledge_unit 表

id TEXT PRIMARY KEY, title TEXT NOT NULL, content TEXT, summary TEXT,
tags TEXT (JSON), difficulty INTEGER, source TEXT,
created_at INTEGER, updated_at INTEGER, review_status INTEGER,
next_review_at INTEGER, interval_days INTEGER, ease_factor REAL, repetitions INTEGER,
prerequisites TEXT (JSON), related TEXT (JSON), embedding TEXT (JSON),
user_id TEXT, version INTEGER DEFAULT 1
// 索引: idx_created_at, idx_review_status, idx_done

NoteItem (UI 视图模型 · NoteItemMapper 转换)

NoteItem {
  id: number,  // stableNumericId(rawId) hash→32位整数
  title: string,  type: string,  subject: string,
  chapter: string,  conf: number,  // 0.45~0.95
  body: string,  // content 或 summary
  tags: string[],  date: string,  // "2026-07-17"
  rawId: string  // KnowledgeUnit.id 原样
}

ReviewStatus→confidence: GRADUATED=0.95, REVIEW=0.86, LEARNING=0.72, LAPSED=0.45, 默认=0.64

五、降级路径

OCR 返回空

Dispatcher.buildFallbackUnit(type, subject) → KnowledgeUnit { title: "概念 · 高代 (待补充)", content: placeholder, difficulty: MEDIUM }

不调 LLM，直接构造最小 KnowledgeUnit 入库

KnowledgeModel LLM 返回空

KnowledgeModel.buildFallbackFromClassify(ocrText, type, subject) → KnowledgeUnit { title: OCR首行, content: ocrText, tags: [type,subject] }

用 TypeClassifier 分类结果构造基础笔记，不丢 OCR 数据

TypeClassifier LLM 不可用

ruleFallback(text) → { type: NoteCategory (5类), subject: string (3门默认), confidence: 0.4~0.5 }

关键词推断：证明→证明题, 计算→计算题, 定理→定理, 公式→公式, 默认→概念
